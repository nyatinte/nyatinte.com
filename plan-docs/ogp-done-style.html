OGP 実績カード風 3案

方針

  • OGP 画像だけを実績カード風にする。アプリの一覧UIは通常のデザインのまま。
  • 階級もエンブレムも無し。GOLD / SILVER / BRONZE を入れず、アイコンも使わない。縦線とタイポだけで見せる。
  • 実在ゲームの名称・アイコン・画面は使わない。構造（縦線＋タイトル＋一言＋メタ）だけを参考にする。
  • 数字は 1200 × 630、summary_large_image、タイトルは最大3行。
