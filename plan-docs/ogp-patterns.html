OGP 画像 3案 / X での見え方

前提

  • 画像は 1200 × 630（1.91:1）。X はこの比率で表示し、違う比率はセンタークロップされる。
  • twitter:card = summary_large_image。5MB 以下、JPG / PNG / WebP。
  • 角丸で端が落ちるので、外周 48px 程度は余白（セーフエリア）にする。
  • タイトルは 76 / 68 / 58 / 48 / 40px の5段階、最大4行。行数と文字量から選び、長いほど小さくする。それでも収まらない長さだけ末尾を省略する。
  • 折返しは BudouX で文節分割 → 行頭の閉じ括弧・行末の開き括弧を補正 → 行幅の二乗誤差が最小の分割を選ぶ。
  • 下のモックは、その計算結果を手で置いたもの。実装では自動でこの形になる。
