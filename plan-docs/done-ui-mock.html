このモックについて
エンブレムの図形は自作のプレースホルダで、トロフィー形状やプラットフォームのロゴは使っていません。実際に採用するときは、この図形をちゃんとデザインし直します。

数字は全部ほんもの
総記録・今月・タグ数・連続記録は D1 から集計できる値です。達成率やレア度は、このアプリに完了という概念が無く算出できないので出していません。

tier は作者が選ぶ任意項目
GOLD / SILVER / BRONZE は自動判定ではなく、投稿時に自分で付ける想定です。付けなければ左の縦線とエンブレムがグレーになります。
