# 0001. 記事ごとの OGP 画像は画像生成 AI で作る

## 状態

採択した。この文書を書いた時点では実装しない。

## 背景

ログの OGP 画像は、記事の frontmatter に `image` がなければ `src/routes/og.png` を使う。`image` がある記事はそのパスか URL を使う。

## 決定

記事ごとの OGP 画像は画像生成 AI で作る。画像を作るプロンプトはスキルにし、記事を置く作業の流れに組み込む。

費用がかかるため、生成もスキルもこの決定では作らない。

## 結果

frontmatter の `image` は残す。生成した画像のパスか URL を、あとからこの欄に書く。共通の `src/routes/og.png` は、`image` がない記事で引き続き使う。
