# Credits

This skill combines three sources. Their licenses are unchanged. The
template, capture rules, and stack commands here are adapted, not copied
in full.

## PR description

[mattpocock/skills `pr`](https://github.com/mattpocock/skills/blob/main/skills/engineering/pr/SKILL.md)
(MIT, Copyright (c) 2026 Matt Pocock) is the description template:
Summary as the smallest visual that makes the change clear, before/after
Evidence, and a Merge Danger call (one-way or two-way door, plus blast
radius).

That skill's visual menu (pseudocode, call trees, component trees, file
trees, Mermaid, diffs) is itself adapted from Dex Horthy's
[`show-me`](https://github.com/humanlayer/humanlayer) skill.

The MIT license text for mattpocock/skills is at
https://github.com/mattpocock/skills/blob/main/LICENSE.
